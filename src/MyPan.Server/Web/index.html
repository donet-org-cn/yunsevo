服务设置 · 文件协议

所有协议共用用户权限、配额、版本历史和回收站。默认关闭；保存后立即应用。

FTP 为明文协议，建议限本机或可信内网。SMB 默认 1445，Linux/macOS 可指定端口；Windows 资源管理器通常需要 445，可在空闲的主机上设置。FTP 被动传输还需允许动态数据端口。

工程拍摄 · 地址与天气

Key 仅在服务端加密存储。手机开启对应水印时才查询，定位坐标会发送到所选服务商。高德使用 GPS 坐标转换后查询；天气保留来源与数据时间，查询失败不会填入虚假信息。
