# 沄序 · Yunsevo：界面与管理更新

产品名称为“沄序文件云”，桌面客户端为“沄序 Drive”，品牌文案为“文件有序，协作从容”。名称已由项目使用者确认；商标和域名可用性尚未独立核验。项目、程序集、命名空间、配置目录及协议名称统一使用 Yunsevo。服务端和客户端应配套更新；升级保留数据与密钥，原客户端配置可通过 `scripts/copy-client-settings.ps1` 复制校验到新目录。Windows 沿用原 Shell 注册标识，并识别相同服务器、账号及云端目录的既有绑定，避免品牌更名导致重新同步。

## 界面

主色为青绿 `#0B8B90`，导航使用深蓝 `#102A39`，工作区底色为 `#F4F7FA`。品牌图形是叠放文件，与网页图标和客户端托盘图标保持一致；所有素材随程序提供。

网页左侧分别进入文件、回收站、用户、用户组、服务设置和审计页面。用户及用户组使用列表加编辑面板；密码重置使用独立弹窗，支持随机密码或指定密码。个人账户可验证当前密码后修改密码。

网页按可用屏幕高度布置表格，表头固定，数据区内部滚动，底部保留分页；文件行约 51 px。窄屏收起侧栏，宽表格在自身区域横向滚动。客户端根据屏幕工作区和缩放比例调整窗口，窄窗收起登录页装饰区；同步任务、活动记录和云端目录选择均有分页。目录选择保留私有、公共、分配给我和权限标签。

## 分页接口

| 接口 | 用途 |
| --- | --- |
| `GET /api/browser/entries` | 文件和回收站；支持 folder、query、trash、sort、descending |
| `GET /api/browser/folders` | 当前用户可选择的同步目录，支持 query |
| `GET /api/browser/versions/{id}` | 文件历史版本 |
| `GET /api/browser/entry?path=...` | 上传前精确查询单个路径，避免获取整个目录 |
| `GET /api/admin/users/page` | 用户搜索与分页 |
| `GET /api/admin/groups/page` | 用户组搜索与分页 |
| `GET /api/admin/audit/page` | 审计搜索，支持 action、user、kind |

分页接口使用 page、pageSize，返回 items、total、page、pageSize；page 从 1 开始，pageSize 限制为 1–100。过滤和权限检查发生在计数及分页之前，越界页会调整到最后一页。文件排序具有稳定的 ID 次序。网页提供 10、20、50、100 条每页，目录选择每页 20 条。

用户组成员和文件夹授权的对象选择器仍使用名称选项；其所在的用户、用户组、文件及审计主列表已分页。同步协议保留原目录接口以兼容现有客户端；网页分页并未将 JSON 存储转换为数据库集群。

## 密码

`POST /api/admin/users/{id}/reset-password` 仅管理员可用。请求 Password 为空时生成 24 字节随机密码的 Base64 表示；指定密码要求 12–256 个字符。仅更新密码哈希和盐，保留角色与目录权限，并撤销该用户的全部会话。生成结果仅在本次响应和弹窗中显示，关闭即清空，不写入审计。

`POST /api/auth/password` 验证 CurrentPassword 并设置 NewPassword，成功后撤销全部会话，需重新登录。当前密码错误返回 400，避免误报成有效会话失效。登录及密码操作使用限流器；每个来源 IP 默认每分钟 60 次，可通过 `Yunsevo__LoginRequestsPerMinute` 设置为 5–600。

## 回收站与来源

删除时记录 UTC 时间、已认证用户 ID、用户名、显示名称、设备名称、来源协议和连接地址。删除目录及其子项共用同一批次和删除来源，恢复后重新删除会产生新的记录。旧回收站数据没有的信息显示“历史记录未留存”或“未上报”，不会拿文件修改时间冒充删除时间。

客户端上报本机名称；网页无法获取真实电脑名称，显示未上报，并保留连接 IP。设备名称是客户端声明的信息，不作为身份凭据。用户名由服务端认证结果确定，不能由请求头指定；地址取自实际连接，只有经内部认证的 SMB 网关可以转交其对端地址。WebDAV、FTP、SMB 的删除也记录对应来源。审计分页搜索覆盖当前日志与保留的轮转日志，不再只显示旧接口最后 300 条。

本次更新保留原始目录数据格式的兼容读取。正式部署仍需备份整个数据目录及相关密钥；同一数据目录只允许一个主服务端写入。
