# 沄序 · Yunsevo Drive v2.6.2

服务端与跨平台同步客户端首个完整 GitHub Release。修复 macOS 托盘初始化时空提示文字引发的启动崩溃。完整截图与操作界面见[截图画廊](https://github.com/hnlyf168/yunsevo/blob/main/docs/screenshots.md)。

## 下载选择

每个平台分别提供三个独立包，解压即可运行，无需安装 .NET：

| 系统 | 架构 | 文件名中的平台标识 |
| --- | --- | --- |
| Windows | Intel/AMD 64 位 | win-x64 |
| Windows | ARM64 | win-arm64 |
| Linux（glibc） | Intel/AMD 64 位 | linux-x64 |
| Linux（glibc） | ARM64 | linux-arm64 |
| macOS | Intel | osx-x64 |
| macOS | Apple Silicon | osx-arm64 |

- **服务端**：yunsevo-server-平台.zip 或 .tar.gz，包含网页管理、SMB 网关、迁移说明及该平台客户端的网页下载包。
- **桌面客户端**：yunsevo-drive-平台.zip 或 .tar.gz，登录、多服务器、多同步目录、托盘面板、同步记录和设置。
- **无界面客户端**：yunsevo-headless-平台.zip 或 .tar.gz，命令行及 Linux systemd 示例。
- **旧版兼容客户端**：yunsevo-legacy-client-win-架构.zip，仅供旧 API 密钥配置迁移，新部署请选择 Drive 桌面客户端。

SHA256SUMS.txt 为校验清单，verification-平台.json 为对应原生程序的检查记录。服务端、Drive 和无界面客户端均为 Native AOT，SMB 网关为自包含托管 .NET。

## 主要功能

- 用户和用户组管理，个人私有、公共及指定用户/组授权目录。
- 文件夹配额、文件版本、回收站及记录删除用户和设备的审计。
- 网页上传、下载、文件夹浏览、文本/图片/浏览器支持的视频预览。
- 多服务器、多同步任务、加密保存登录、托盘活动面板。
- 分块续传、流式传输、变更推送和条件写入，离线删除需用户确认。
- 首次安装设置管理员和存储路径，一键迁移备份；网页刷新恢复会话及原位置。

## 部署与验证范围

新服务端启动后打开 http://服务器地址:5080，使用服务端同目录 setup-code.txt 完成初始化。跨设备客户端登录需要受信任的 HTTPS。保留解压目录内的原生依赖、许可证和 smb 子目录；升级前导出备份并保留服务端配置和数据。

每个平台先生成并解压最终发布包，再检查二进制架构、服务启动、账号登录、文件上传下载、无界面客户端双向同步、桌面客户端同步及真实 Avalonia 窗口渲染。详细检查项目以各平台 verification 附件为准。desktop-平台.png 为该平台实际渲染的登录窗口截图。CI 冒烟检查不等同完整桌面环境与大规模压力验收。

Windows 使用 CFAPI 提供资源管理器按需下载；Linux/macOS 当前完整下载同步，尚无跨平台虚拟占位文件。Windows ARM64 的 CFAPI 仍需设备上的完整回归。Linux 包需要 glibc 和桌面图形运行库，不适用于 Alpine/musl。

Windows 尚无商业代码签名，macOS 尚无 Apple Developer ID 签名或公证。图片中的数据来自隔离演示环境，桌面示例为 Windows 实际运行界面；其他系统的字体、窗口及托盘表现可能不同。
