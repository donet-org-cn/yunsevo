# 沄序 · Yunsevo v2.7.0

服务端与跨平台客户端统一使用 Yunsevo 项目、程序集、命名空间及程序文件名。本版移除三维扫描拍摄、选帧、模型生成引擎、相关文档及剩余的拼接工具，保留网页与 Android 的已有 GLB 模型旋转、缩放、自动环绕、预览、下载和分享。已有照片、视频、GLB 及回收站内容不删除。项目源码和测试不再依赖 Python。

## 升级

1. 先通过服务端网页导出整站备份，保留 `api-key.txt`、`server-settings.json` 及完整数据目录。停止旧服务端和客户端后更新整套发布目录，保留原配置及数据；不要以空包覆盖数据目录。
2. 服务端与客户端应配套升级：环境变量使用 `Yunsevo__*` / `YUNSEVO_*`，程序文件名使用 `Yunsevo.*`。已有账户、权限、版本及回收站数据继续读取，网页登录可能需要重新登录。
3. 桌面设置目录改为 `YunsevoDesktop`。旧设置可使用仓库的 `scripts/copy-client-settings.ps1 -Source 旧目录 -Destination 新目录` 复制并逐文件校验，原目录保留。Windows 沿用已注册同步目录的 OS 标识，并识别相同服务器、账号与云端目录的旧绑定；不要删除原同步状态。
4. 若迁移源码工作区根目录，关闭占用它的程序后运行 `scripts/rename-workspace.ps1`；脚本会同步更新本机安装配置中指向该工作区的数据路径。

## 验证与边界

发布流程对六个平台的最终压缩包执行解压、二进制架构、服务启动、账号登录、文件上传下载、桌面与无界面同步及真实 Avalonia 窗口渲染检查。Android 检查 Mono AOT 库、离线模型查看资源、移除的生成依赖和签名证书，附件记录对应提交与 SHA-256。

本地 Windows CFAPI/Native AOT 回归通过 140 项；Android 模拟器日常流程 36 项、已有模型查看 11 项通过。照片元数据测试已改用 Node.js，并以真实拍摄样本验证。CI 冒烟检查不等同于所有实际设备和大规模压力验收。

Windows 支持 CFAPI 按需下载；Linux/macOS 当前同步完整本地副本。Windows 尚无商业代码签名，macOS 尚无 Developer ID 签名或公证；Android 沿用内部测试证书，尚非应用商店生产签名。
