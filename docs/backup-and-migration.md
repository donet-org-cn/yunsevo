# 备份、迁移与默认个人目录

## 网页一键备份

管理员登录后进入“服务设置 → 迁移与备份 → 下载迁移备份（ZIP）”。文件由浏览器下载，地址中不携带登录令牌。普通用户不能导出整站备份。

导出的包包含：当前目录、文件内容、历史版本、回收站及删除来源、用户与用户组、权限、容量和版本保留设置、协议配置、SMB 专用凭据及其加密密钥、保留的审计日志、API 密钥、逐文件长度和 SHA-256 清单。包不包含未完成的上传、SMB 暂存文件、锁文件、无引用的孤立 blob 和旧目录备份副本。网页登录会话不迁移，恢复后账号客户端需重新登录；原 API 密钥保持兼容。

生成期间暂停提交目录变更，文件、历史版本和回收站来自同一修订。生成完成后恢复提交，并流式发送 ZIP；服务端临时目录需要容纳整份备份的可用空间。断开下载会清理该次临时包。备份操作写入原服务器的审计记录。

备份含敏感密钥与账户数据，应存放在受控位置。SHA-256 用于检验包内容完整性，不是数字签名。HTTPS 证书、环境变量、反向代理、监听地址及系统防火墙需在新机器另行配置。

## 恢复到新机器

安装相同或更新版本的完整服务端包，使用包内 `restore-backup.ps1`。恢复目标必须是尚不存在的新目录，父目录需已存在；脚本会校验路径、重复项、长度和 SHA-256，校验全部通过后才发布恢复目录，不覆盖现有数据。失败的中间目录会保留并显示路径，便于排查。

Windows 示例，在服务端程序目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\restore-backup.ps1 -Archive D:\yunsevo-backup.zip -Destination D:\Yunsevo-Restored
$env:MyPan__DataPath = 'D:\Yunsevo-Restored\data'
$env:MyPan__ApiKeyFile = 'D:\Yunsevo-Restored\api-key.txt'
Remove-Item Env:\MyPan__ApiKey -ErrorAction SilentlyContinue
.\MyPan.Server.exe
```

项目源码中的脚本位于 `scripts/restore-backup.ps1`。Linux/macOS 可使用 PowerShell 7 执行同一脚本；原生服务端程序须使用对应系统的发行包，Unix 恢复脚本尚未实机验证。

先在新服务器验证登录、文件下载、历史版本与回收站，再切换客户端地址。尽量保持原服务器域名，目录和文件 ID 会保留。切换完成后停止旧服务器的写入，避免形成两份独立变化的数据。同一数据目录只允许一个主服务端写入；此导出不是持续复制或自动故障切换。

## 个人目录与双击操作

每个账户默认拥有 `个人/用户名`，包括初始管理员和旧账户；升级时自动补齐，修改前保留目录数据库副本。默认个人目录及其分组不能移动、重命名或删除，根目录始终保持本人的私有策略。其他普通用户无法看到或下载其中的内容，即使子目录有公用设置也不能越过此边界。管理员保留管理权限；要共享文件，请放入公共或指定授权目录。配额和版本保留仍可由管理员设置。

文件列表双击文件夹进入，双击支持的文件格式预览，不支持的格式直接下载。现有文件夹名称仍可单击进入。回收站文件可下载或预览，无需先恢复；目录仍以恢复为单位，不提供目录 ZIP 下载。文本按纯文本显示，图片和媒体沿用浏览器能力，视频与下载支持字节范围请求。

新增接口：`GET /api/admin/backup`、`GET /api/trash/{id}/content`、`GET /api/trash/{id}/preview`。回收站读取接口支持 version 参数和原有授权检查，项目被永久删除后返回 404。
