# 沄序 Drive 桌面界面

客户端以 Synology Drive Client 的紧凑任务管理方式、OneDrive 的托盘状态面板作为交互参考，使用沄序品牌、青色主色和随程序提供的矢量图标。

## 托盘

单击托盘图标展开状态面板，单击外部收起。顶部显示当前账户和实际同步状态：未登录、正在同步、已为最新、部分任务暂停、连接断开或需要处理。右上角齿轮打开全局设置。

“最近更改”显示实际文件活动，包含文件名、任务、操作及相对时间；显示最近 12 个不同的任务/文件/操作组合，更多记录在同步日志中分页查看。“通知”只显示当前连接问题和等待处理的删除，不生成示例通知。退出登录后，托盘不显示之前的文件列表。

底部四个入口：

- 打开文件夹：打开所选任务的本地目录；未选择时打开第一个任务目录。
- 在线查看：打开当前服务器的网页。
- 管理任务：打开完整任务窗口。
- 同步日志：打开日志页面。

右键托盘仍可打开主窗口、暂停/继续全部任务和退出。窗口关闭默认保留后台同步，可在设置中改为退出；从托盘选择“退出沄序”始终停止任务并退出。

## 主窗口

左侧为同步任务、同步日志、通知、全局设置。同步任务按服务器连接分组，可同时连接多个服务器、不同账户；每个服务器下可添加多个同步文件夹。服务器标题旁的加号添加目录，暂停和继续仅操作该服务器，齿轮管理此连接。选中任务后可用顶部工具栏暂停、继续、删除或修改任务名称。删除任务会保留原有本地目录、同步状态和云端文件。

搜索与分页用于控制列表大小；切换页或搜索后，隐藏的任务不保留操作选择，避免误操作。窗口较小时隐藏搜索框，保留任务管理与分页。任务的目录和下载方式保持原有安全流程，通过移除后重新创建来变更。

点击“创建”，先选择已有服务器或添加新服务器，再进入三步目录向导：选择云端目录、设置本地目录与下载方式、确认任务。确认页可勾选“完成后继续为此服务器添加文件夹”。目录按权限标注私有、公共、分配给我；路径分组不能作为同步根。个人根目录在客户端显示为 `/个人`，实际路径和同步状态标识保持兼容。

## 自动登录与权限

登录成功会保存可撤销的设备凭据，不保存账户密码。正常退出或重启后，客户端自动恢复各服务器连接并启动已启用任务，保留原先暂停的任务。服务器暂不可达时独立重试，不影响其他连接。密码重置、账户停用、手动退出登录会使对应凭据失效。设备凭据有效期为 90 天，启动和运行期间验证并续期；连续 90 天未使用后需要重新登录。

凭据文件是客户端配置目录下的 `credentials/accounts.bin`。Windows 使用当前用户的 DPAPI 加密。Linux/macOS 使用 AES-GCM 加密及权限为 0600 的独立密钥 `credentials/key.bin`，凭据子目录为 0700；这依赖当前系统账户和文件权限，不等同于硬件密钥保护。不要向其他用户复制凭据目录。`preferences.json` 仍只保存服务器提示和任务配置。

服务器为设备登录签发受限会话。即使账户是管理员，客户端也只能访问自己的个人目录和按权限开放的公共、指定授权目录；不能读取其他用户的私有文件、预览、版本或回收站，不能调用网页管理接口。只有网页管理员会话保留管理权限，设备会话兑换新会话不会提升权限。旧版共享 API 密钥仍是管理员兼容凭据，建议迁移后关闭 `MyPan__AllowLegacyApiKey`。

账户页“添加服务器连接”保留当前所有连接。“退出当前服务器登录”撤销该连接、清除本机对应凭据并停止其任务，其他服务器继续同步；文件和任务配置保留。任务列表点击服务器标题可切换账户页及使用量的当前连接。

## 设置与日志

全局设置分为常规、显示、使用量和账户。显示选项保存到客户端配置目录的 `display.json`，不修改原有 `preferences.json` 的任务身份。支持紧凑行、显示完整云端路径、显示托盘最近活动。

使用量由服务器的授权目录及权限接口读取，包含文件、历史版本和回收站。本层没有配额时显示“本层未设上限”，仍可能受父目录配额约束；父子目录数据有重叠，不相加。目录和使用量按页加载，账户切换时清理缓存。

同步日志支持搜索、文件活动/需要处理筛选和分页。运行中最多保留最近 1000 条界面记录，启动时载入最近 150 条；完整日志仍按天存储并可打开目录查看。Windows 按需下载完成记录使用相对文件名，便于在活动面板识别。

v2.6.2 已在 Windows、Linux、macOS 的 x64/ARM64 原生主机上分别构建，并从最终发布包解压运行。六个平台均通过 12 项原生架构、服务登录、文件传输、客户端同步与真实 Avalonia 登录窗口渲染检查，见 [Release](https://github.com/hnlyf168/yunsevo/releases/tag/v2.6.2) 的 verification 附件及[原生窗口截图](screenshots.md)。同时修复 macOS 托盘附加前提示文字为 null 引发的启动崩溃。

这些检查不等同完整桌面验收：Linux 各桌面环境、macOS 托盘透明面板及定位仍需实际环境验证；Windows ARM64 的 CFAPI 仍需单独回归。Linux/macOS 目前完整下载同步，macOS 未进行 Apple Developer ID 签名或公证。
